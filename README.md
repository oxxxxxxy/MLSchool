# 🧠 ML Kids Academy (Монорепозиторий Онлайн-Школы ML)

Интерактивная образовательная онлайн-школа по машинному обучению, созданная специально для школьников **7 класса (12–13 лет)**.

Архитектура построена в виде **Yarn Workspaces монорепозитория** с полноценным бэкендом на NestJS, клиентским приложением на React 19 + Vite, отдельной админ-панелью для мониторинга успеваемости и Playwright E2E тестами.

---

## 📚 5 Фундаментальных Интерактивных Уроков Математики для ML

1. **Урок 1: Что такое Функция? Магический автомат и правила мира**
   - ⚙️ **Магический конвейер**: бросаем шары с числами $x$ и смотрим на шестеренки функции $f(x)$.
   - 📈 **Трассировщик декартова графика**: живое перо на координатной сетке рисует кривую вслед за движением $x$.
   - 💥 **Сломай автомат делением на 0**: гипербола $y = 10/x$, запретные зоны и область определения $D(f)$.
   - 🎮 **Взломщик правил (Реверс-инжиниринг)**: отгадай скрытый закон автомата по тестовым испытаниям.

2. **Урок 2: Линейная функция $y = kx + b$ — Фундамент всего ИИ**
   - 📐 **Лаборатория прямой линии**: ползунки наклона $k$ (веса) и сдвига $b$ (bias), кликабельное добавление точек данных.
   - 🔺 **Треугольник крутизны $\Delta y / \Delta x$**: ступенька шага по горизонтали и подъема по вертикали.
   - 🎯 **Игра «Лазерный стрелок»**: подбери $k$ и $b$, чтобы луч лазера поразил летающие дроны-мишени.

3. **Урок 3: Кривые и Нелинейность — Параболы, Чаши и Оптимум ($y = ax^2 + bx + c$)**
   - 🥣 **Анатомия параболы**: чаша $a > 0$ vs купол $a < 0$, поиск вершины (минимума).
   - 🚀 **Гонка ракет**: визуальное сравнение линейного $8x$ и квадратичного $x^2$ роста.
   - ⚽ **Физика шарика на дне чаши (Loss Bowl)**: 60 FPS симуляция скатывания мячика в точку минимума ошибки.

4. **Урок 4: Производная — «Куда дует ветер?» ($f'(x)$)**
   - 🏎️ **Спидометр vs Одометр**: мгновенная скорость изменений прямо сейчас.
   - 📏 **От секущей к касательной ($\Delta x \to 0$)**: сближаем точки на параболе и получаем точный наклон Лейбница.
   - 🔍 **Микроскоп касательной**: любая кривая под увеличением превращается в прямую линию.
   - 🧗 **Игра «Слепой альпинист в тумане»**: пошаговый спуск на дно ущелья по знаку производной (интуиция Gradient Descent!).

5. **Урок 5: Векторы, Признаки и Граф Нейрона (Мостик в ML)**
   - 🏹 **Векторная 2D лаборатория**: вектор как паспорт объекта, сложение стрелок $\vec{u} + \vec{v}$, масштабирование.
   - 🧭 **Компас схожести (Cosine Similarity)**: как ChatGPT и поиск сравнивают смысл текстов и картинок через косинус угла $\theta$.
   - ⚡ **Вычислительный граф нейрона на React Flow**: входы $x_1, x_2$, веса связей $w_1, w_2$, сумматор $\Sigma + b$, активация ReLU и прогноз $\hat{y}$.
   - 🎓 **Итоговый выпускной экзамен** с вручением персонального диплома «Математик-Датасаентист».

## 🏛️ Структура Монорепозитория (`packages/*`)

```
ml-school-monorepo/
├── packages/
│   ├── shared/   # TypeScript интерфейсы, DTO, математический движок MathEngine
│   ├── api/      # NestJS 10 backend + Swagger Docs на http://localhost:4000/api/docs
│   ├── web/      # Главный обучающий портал: React 19 + Vite + Tailwind + KaTeX + React Flow (http://localhost:5173)
│   ├── admin/    # Админ-панель аналитики успеваемости (http://localhost:5174)
│   └── tests/    # Playwright E2E тесты
```

## 🚀 Быстрый запуск

### 1. Перейти в каталог проекта:
```bash
cd /home/pyot/.gemini/antigravity/scratch/ml-school-monorepo
```

### 2. Запустить клиентское веб-приложение:
```bash
yarn dev:web
```
Откройте браузер по адресу: `http://localhost:5173`

### 3. Запустить бэкенд NestJS (с Swagger документацией):
```bash
yarn dev:api
```
Swagger UI: `http://localhost:4000/api/docs`

### 4. Запустить админ-панель:
```bash
yarn dev:admin
```
Админка: `http://localhost:5174`

### 5. Собрать все пакеты для продакшена:
```bash
yarn build
```
